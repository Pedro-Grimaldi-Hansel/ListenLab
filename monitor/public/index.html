COMO ACOMPANHAR

Seu coletor, à vista.

O sinal confirma o agendador. Ele é atualizado a cada 5 segundos, inclusive enquanto uma coleta está em andamento. Se deixar de chegar, o monitor avisa.

A próxima coleta usa o intervalo em execução. Fechar esta aba não interrompe o coletor. O computador e o Docker precisam continuar ligados.

A atualização da página só consulta o banco. A busca no Spotify continua seguindo o intervalo do agendador.

Para iniciar a coleta automática, execute na pasta do projeto:

docker compose --profile schedule up -d scheduler

Depois de alterar o intervalo no .env, recrie o agendador:

docker compose --profile schedule up -d --force-recreate scheduler

Para conferir os arquivos originais:

docker compose run --rm app php app raw:verify

Armazenamento: respostas idênticas compartilham conteúdo e são compactadas sem perdas. O backup diário é restaurado e conferido antes de liberar cópias ativas antigas. A pasta privada fica neste projeto e precisa também de cópia em outro disco.

O histórico inclui coletas manuais, investigações da janela e reprocessamentos. A integridade dos arquivos é conferida pelo comando de verificação; o monitor exibe os registros de origem.
